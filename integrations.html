API & Integrations

Where NovaClip gets real creator numbers from. Every credential lives on the integrations Worker — nothing is stored in this page, and no key is ever sent to a browser. This screen can only ever see configured or missing.

Platforms

Green means the credentials are present. Test Connection makes a real call.

What each one needs, and what it can actually do.
  • YouTube — an API key. No consent screen, no approval. Reads any public channel.
  • Twitch — client id and secret. No user consent. Public channel data; the follower count is available, the follower list is not.
  • TikTok — user OAuth. Reads only the account that connects. Looking up other creators needs the Research API, which is a separate application.
  • Instagram — user OAuth, and the account must be a Creator or Business account linked to a Facebook Page. A personal account cannot return insights.
Nothing here invents numbers. If a platform is not configured, this page says so and offers demo data explicitly. If a configured platform fails, you get the real error — a dashboard that quietly swaps in made-up figures when the API is down is worse than one that admits it is down.
